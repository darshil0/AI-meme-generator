# AI Meme Generator 🤖

**Your personal AI-powered meme factory. Create viral-worthy memes in seconds with the power of generative AI.**

This interactive web application allows you to create hilarious memes by combining images with AI-generated captions. Upload your own picture or choose from a library of popular templates, and let the Gemini AI suggest witty and relevant captions tailored to the image.

## ✨ Features

### 🖼️ Flexible Image Options

- Upload your own image files (JPG, PNG, GIF, WebP) - up to 10MB
- Select from a curated list of 13+ popular, trending meme templates
- Save your uploaded images as custom, reusable templates
- Search through templates with real-time filtering
- Template caching for faster loading

### 🧠 Magic AI Captions

- Click the "Magic Captions" button to get 5 unique, funny captions generated by Google's Gemini AI
- The AI analyzes the image content (or template name) to provide contextually relevant suggestions
- Refine AI suggestions by providing a custom tone:
  - **Humorous** - Classic funny memes
  - **Sarcastic** - Witty and ironic
  - **Wholesome** - Heartwarming and positive
  - **Absurd** - Random and surreal
  - **Dark** - Edgy humor
- Add optional context to guide caption generation

### ✏️ Powerful Text Editor

- Add unlimited text layers to your meme
- Customize for each layer:
  - Font size (10-200px)
  - Font color (full color picker)
  - Outline color for classic meme look
  - Text blur effect (0-10px)
  - Vertical positioning (0-100%)
- Reorder layers with up/down controls
- Select and edit individual layers

### 🎨 Image Filters

- Apply filters to change the mood:
  - None (original)
  - Grayscale
  - Sepia
  - Invert
  - Blur
  - Brightness
  - Contrast

### 💾 Session Management

- **Save Work**: Save your entire meme creation (image, text layers, filters, settings) to browser's durable storage
- **Load Work**: Resume a previous editing session with a single click
- State persistence across browser sessions with IndexedDB for high-capacity storage
- Custom templates saved permanently using `idb-keyval`
- Backward compatibility with older LocalStorage formats

### 🚀 Export & Share

- Download your final meme as a high-quality JPEG file
- Quality options: High (Original 95%), High (92%), Medium (75%), Low (50%)
- Copy the meme directly to your clipboard to easily paste and share
- Visual feedback for copy/save actions
- Automatic error handling for storage and clipboard operations

## 🧠 How It Works

The core of this application is its integration with the **Google Gemini API**. When a user requests "Magic Captions," one of two things happens:

1. **If an image is uploaded:** The application sends the image data (as a base64 string) and the selected tone/context to the Gemini model. The model analyzes the visual content and generates captions based on its understanding of the image.

2. **If a template is selected:** The application sends the name of the template (e.g., "Distracted Boyfriend") to the model, which uses its vast knowledge of internet culture to generate appropriate captions for that specific meme format.

The AI is prompted to return the results in a structured JSON format, which the application then parses and displays as clickable suggestions. The service includes robust error handling and sanitization to ensure safe, reliable responses.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn
- Google Gemini API key

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd ai-meme-generator
```

2. Install dependencies:

```bash
npm install
```

3. Configure your API key:

Edit `src/environments/environment.ts` and add your Gemini API key:

```typescript
export const environment = {
  production: false,
  // TODO: Replace this placeholder with your real Gemini API key for production use.
  apiKey: 'YOUR_GEMINI_API_KEY_HERE',
};
```

**For production builds**, use Angular's file replacement feature in `angular.json` to replace `environment.ts` with `environment.prod.ts` containing your production API key.

**Important**: Never commit your API key to version control. Use environment variables or secure configuration management for production deployments.

4. Obtain your API key from [Google AI Studio](https://aistudio.google.com/app/apikey).

### Running the Application

#### 1. Start the backend (Gemini proxy)

The backend service lives in the `server/` directory and is responsible for:

- Talking to the Google Gemini API (your API key lives **only** on the server)
- Proxying external meme template images to avoid CORS issues

```bash
cd server
npm install        # first time only
$env:GEMINI_API_KEY="YOUR_REAL_GEMINI_KEY"   # PowerShell example; use env vars in prod
npm run dev        # runs on http://localhost:4000
```

#### 2. Start the Angular frontend

```bash
cd ..
npm install        # if not already
npm run dev        # Angular dev server with /api proxy
```

The application will be available at `http://localhost:4200`, and all `/api` calls are automatically proxied to the backend via `proxy.conf.json`.

**Production build:**

```bash
npm run build
```

**Preview production build:**

```bash
npm run preview
```

### Deployment (overview)

This project is split into a frontend (Angular) and a backend (Express proxy):

1. **Backend (server/)**
   - Deploy `server/` to your platform of choice (e.g., Render, Railway, Cloud Run, or a Node-compatible host).
   - Set environment variables:
     - `GEMINI_API_KEY` – your real Gemini API key (never checked into git).
     - `ALLOWED_ORIGIN` – your frontend origin (e.g., `https://your-domain.com`).
   - Expose the backend at a URL like `https://your-backend.example.com`.

2. **Frontend (Angular)**
   - Build the frontend with `npm run build` and deploy the contents of `dist/` to a static host (Vercel, Netlify, CloudFront, etc.).
   - Configure the frontend's `/api` base URL to point at your backend host (e.g., via environment-specific configuration or a reverse proxy in front of both services).

In many setups, you can also run the backend and frontend behind a single reverse proxy (e.g., Nginx or a PaaS routing layer) where `/` serves the Angular app and `/api` is forwarded to the Node backend.

### Linting & Formatting

This project uses ESLint and Prettier for code quality and consistent formatting:

```bash
npm run lint    # Run ESLint on TypeScript files
npm run format  # Format the codebase with Prettier
```

## 🎯 Key Features Explained

### Signal-Based State Management

The application uses Angular Signals for reactive state management:

- **Primitive Signals**: `selectedImage`, `layers`, `isLoading`, `error`
- **Computed Signals**: `hasImage`, `selectedLayer`, `computedImageFilter`, `templates`
- **Benefits**: Fine-grained reactivity, no Zone.js overhead, automatic UI updates

### Canvas-Based Rendering

Memes are generated using the HTML5 Canvas API:

1. Creates an offscreen canvas matching image dimensions
2. Applies image filters (CSS filter → canvas filter)
3. Draws text layers with custom styling
4. Exports as JPEG with configurable quality
5. Supports clipboard copying via Clipboard API

### Template Caching

- Remote templates are converted to data URLs on first use
- Cached in memory for instant subsequent access
- Custom templates stored in localStorage as base64 data URLs
- CORS-safe approach for cross-origin images

### Local Storage Persistence

Two types of data are persisted:

1. **Session State** (`savedMemeState`):
   - Current image
   - All text layers
   - Active filters
   - User preferences (tone, context)

2. **Custom Templates** (`customMemeTemplates`):
   - User-uploaded images saved as templates
   - Persisted across sessions

## 🔒 Security Considerations

### Input Sanitization

- AI-generated captions are sanitized to remove HTML tags
- User context is clearly marked as non-executable in prompts
- File type validation on image uploads
- File size validation (10MB maximum)

### API Key Security

- API key should **never** be committed to version control
- Use environment variables or file replacements for all deployments
- A small backend proxy (this repo's `server/` app) holds the real Gemini API key and exposes only `/api` endpoints to the frontend
- Frontend `environment.ts` should **not** contain a real production key; configure secrets via backend env vars instead

### CORS Handling

- Template images are loaded via `/api/template-image?url=...`, a server-side proxy that fetches from approved hosts (including Imgur, Imgflip, Giphy, Unsplash, and more) and returns bytes to the browser
- This avoids direct cross-origin image access from the client and reduces CORS-related failures
- Canvas conversion is performed on proxied images with graceful fallbacks when fetches fail

### Type Safety

- Full TypeScript strict mode compliance
- Proper type guards for error handling
- No unsafe type assertions in production code

## 🐛 Known Limitations

1. **CORS Restrictions**: Some external meme templates may not load due to CORS policies. The app handles this gracefully by still allowing caption generation.

2. **Browser Storage**: Local storage has size limits (~5-10MB). Large custom template collections may hit these limits. The app includes error handling for storage quota exceeded scenarios and provides UI controls to clear saved work and all custom templates.

3. **Clipboard API**: Copy to clipboard requires a secure context (HTTPS) and may not work in all browsers. The app provides a fallback download option.

4. **Mobile Experience**: While responsive, the editor experience is optimized for desktop/tablet use.

5. **API Key Security**: For production deployments, consider using a backend proxy to keep your API key secure rather than exposing it in the client-side code.
