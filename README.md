# AI Meme Generator 🤖

**Your personal AI-powered meme factory. Create viral-worthy memes in seconds with the power of generative AI.**

This interactive web application allows you to create hilarious memes by combining images with AI-generated captions. Upload your own picture or choose from a library of popular templates, and let the Gemini AI suggest witty and relevant captions tailored to the image.

---

## ✨ Features

*   **🖼️ Flexible Image Options:**
    *   Upload your own image files.
    *   Select from a curated list of popular, trending meme templates.
    *   Save your uploaded images as custom, reusable templates.
*   **🧠 Magic AI Captions:**
    *   Click the "Magic Captions" button to get 5 unique, funny captions generated by Google's Gemini AI.
    *   The AI analyzes the image content (or template name) to provide contextually relevant suggestions.
    *   Refine AI suggestions by providing a custom tone (e.g., humorous, sarcastic, wholesome) and optional context.
*   **✏️ Powerful Text Editor:**
    *   Add multiple text layers to your meme.
    *   Customize font size, color, and outline color for the classic meme look.
    *   Adjust vertical positioning with a simple slider.
    *   Apply a blur effect to text for creative emphasis.
*   **🎨 Image Filters:**
    *   Apply filters like grayscale, sepia, and invert to change the mood of your meme.
*   **💾 Session Management:**
    *   **Save Work:** Save your entire meme creation (image, text layers, filters) to your browser's local storage.
    *   **Load Work:** Resume a previous editing session with a single click.
*   **🚀 Export & Share:**
    *   Download your final meme as a high-quality PNG file.
    *   Copy the meme directly to your clipboard to easily paste and share.

---

## 🧠 How It Works

The core of this application is its integration with the **Google Gemini API**. When a user requests "Magic Captions," one of two things happens:

1.  **If an image is uploaded:** The application sends the image data (as a base64 string) and the selected tone/context to the Gemini model. The model analyzes the visual content and generates captions based on its understanding of the image.
2.  **If a template is selected:** The application sends the name of the template (e.g., "Distracted Boyfriend") to the model, which uses its vast knowledge of internet culture to generate appropriate captions for that specific meme format.

The AI is prompted to return the results in a structured JSON format, which the application then parses and displays as clickable suggestions.

## 🚀 Getting Started

To use the AI-powered features of this application, you must have a Google Gemini API key.

### Configuration

The application is designed to securely access the API key from an environment variable.

1.  Obtain your API key from [Google AI Studio](https://aistudio.google.com/app/apikey).
2.  The application expects the API key to be available in `process.env.API_KEY`. When deploying or running this project, you must ensure this environment variable is set.

The application will show a warning if the API key is not configured, and the "Magic Captions" feature will be disabled.

### State Management with Signals

The application leverages **Angular Signals** for reactive state management. This modern, fine-grained approach avoids the overhead of Zone.js and provides excellent performance.

-   All dynamic state within the `MemeEditorComponent` (e.g., `selectedImage`, `layers`, `isLoading`) is managed by `signal()`.
-   Derived state (e.g., `hasImage`, `selectedLayer`, `computedImageFilter`) is efficiently calculated using `computed()`, which only re-evaluates when its dependencies change.
-   UI updates are triggered automatically and precisely when a signal's value is modified via `.set()` or `.update()`.

### Component Breakdown

*   **`AppComponent`**: The root component of the application. It provides the main layout, including the header and footer, and acts as the entry point for the `MemeEditorComponent`.

*   **`MemeEditorComponent`**: The heart of the application. This large but well-structured component is responsible for:
    *   **UI Logic:** Handling all user interactions, from file uploads and template selection to text styling.
    *   **State Management:** Holding all the state signals that drive the editor's UI.
    *   **Canvas & Preview:** Managing the live preview of the meme.
    *   **AI Interaction:** Orchestrating calls to the `GeminiService` to fetch AI captions.
    *   **Exporting:** Generating the final meme image for download or clipboard copy.

### Service Breakdown

*   **`GeminiService`**: This service encapsulates all communication with the Google Gemini API.
    *   **Initialization:** It safely initializes the `@google/genai` client, checking for the presence of the `API_KEY` in the environment variables.
    *   **`generateMemeCaptions()`**: This method takes image data (base64), a MIME type, and user-defined tone/context. It constructs a prompt, sends it to the Gemini model along with the image, and requests a JSON response.
    *   **`generateCaptionsFromText()`**: A similar method that works without an image, using only a template name (e.g., "Surprised Pikachu") to generate contextually relevant captions.
    *   **Error Handling & Parsing:** It includes robust logic to parse the expected JSON array from the AI's response and handle potential errors gracefully.

### Core Logic Walkthrough

1.  **Image Handling:**
    *   **Upload:** When a user selects a file, the `onFileSelected` method uses a `FileReader` to read the image as a Data URL. This allows for an instant local preview without a server round-trip.
    *   **Template:** When a template is selected, the application first checks an in-memory cache. If not present, it uses `new Image()` and an offscreen `<canvas>` to fetch the remote image (respecting CORS) and convert it into a Data URL. This conversion is crucial for enabling canvas manipulation and reliable exporting.

2.  **Canvas Generation:**
    *   The `_generateMemeCanvas()` method is the core of the export functionality.
    *   It creates a new `<canvas>` element with the same dimensions as the source image.
    *   It draws the source image onto the canvas, applying any active image filters (`grayscale`, `sepia`, etc.).
    *   It then iterates through each `TextLayer`, carefully calculating the position and applying all styling (font size, color, outline, blur) before drawing the text onto the canvas.
    *   This canvas is then used by `downloadMeme()` and `copyMemeToClipboard()` to get the final image as a PNG.

3.  **Local Storage Persistence:**
    *   **Session State:** The `saveState()` method serializes the critical parts of the editor's state (current image, layers, filters) into a JSON object and saves it to `localStorage` under the key `savedMemeState`. The `loadState()` method does the reverse.
    *   **Custom Templates:** When a user saves a custom template, it's added to an array that is also persisted in `localStorage`, making custom templates available across sessions.
