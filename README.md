# AI Meme Generator 🤖

**Your personal AI-powered meme factory. Create viral-worthy memes in seconds with the power of generative AI.**

This interactive web application allows you to create hilarious memes by combining images with AI-generated captions. Upload your own picture or choose from a library of popular templates, and let the Gemini AI suggest witty and relevant captions tailored to the image.

## ✨ Features

### 🖼️ Flexible Image Options

- Upload your own image files (JPG, PNG, GIF, WebP) – up to 10MB
- Select from a curated list of 13+ popular, trending meme templates
- Save your uploaded images as custom, reusable templates
- Search through templates with real-time filtering
- Template caching for faster loading

### 🧠 Magic AI Captions

- Click the "Magic Captions" button to get 5 unique, funny captions generated by Google's Gemini AI
- The AI analyzes the image content (or template name) to provide contextually relevant suggestions
- Refine AI suggestions by providing a custom tone:
  - **Humorous** – Classic funny memes
  - **Sarcastic** – Witty and ironic
  - **Wholesome** – Heartwarming and positive
  - **Absurd** – Random and surreal
  - **Dark** – Edgy humor
- Add optional context to guide caption generation

### ✏️ Powerful Text Editor

- Add unlimited text layers to your meme
- Customize each layer with:
  - Font size (10–200px)
  - Font color (full color picker)
  - Outline color for classic meme look
  - Text blur effect (0–10px)
  - Vertical positioning (0–100%)
- Reorder layers with up/down controls
- Select and edit individual layers

### 🎨 Image Filters

- Apply filters to change the mood:
  - None (original)
  - Grayscale
  - Sepia
  - Invert
  - Blur
  - Brightness
  - Contrast

### 💾 Session Management

- **Save Work**: Save your entire meme creation (image, text layers, filters, settings) to browser's durable storage
- **Load Work**: Resume a previous editing session with a single click
- State persistence across browser sessions with IndexedDB for high-capacity storage
- Custom templates saved permanently using `idb-keyval`
- Backward compatibility with older LocalStorage formats

### 🚀 Export & Share

- Download your final meme as a high-quality JPEG file
- Quality options: High (95%), High (92%), Medium (75%), Low (50%)
- Copy the meme directly to your clipboard to easily paste and share
- Visual feedback for copy/save actions
- Automatic error handling for storage and clipboard operations

## 🧠 How It Works

The core of this application is its integration with the **Google Gemini API**. When a user requests "Magic Captions," one of two things happens:

1. **If an image is uploaded:** The application sends the image data (as a base64 string) and the selected tone/context to the Gemini model. The model analyzes the visual content and generates captions based on its understanding of the image.

2. **If a template is selected:** The application sends the name of the template (e.g., "Distracted Boyfriend") to the model, which uses its vast knowledge of internet culture to generate appropriate captions for that specific meme format.

The AI is prompted to return results in structured JSON format, which the application then parses and displays as clickable suggestions. The service includes robust error handling and sanitization to ensure safe, reliable responses.

## 🚀 Getting Started

### Prerequisites

**System Requirements:**
- Node.js (v18 or higher)
- npm or yarn

**For Backend Development (image processing):**
- Cairo (system library) – required for the `canvas` package
  - **macOS:** `brew install cairo`
  - **Ubuntu/Debian:** `sudo apt-get install libcairo2-dev`
  - **Windows:** Included via `node-gyp` (native build tools required)

**API Requirements:**
- Google Gemini API key (obtain from [Google AI Studio](https://aistudio.google.com/app/apikey))

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd ai-meme-generator
```

2. Install dependencies:

```bash
npm install
```

3. Configure API Keys

**Development Setup:**

Create a `.env` file in the `server/` directory (never commit this):

```env
GEMINI_API_KEY=your_actual_gemini_api_key_here
ALLOWED_ORIGIN=http://localhost:4200
NODE_ENV=development
```

The backend will read this file and never expose the API key to the client.

**Production Setup:**

Use your platform's environment variable management (e.g., GitHub Secrets, Vercel Env Vars, etc.) to set `GEMINI_API_KEY` securely. Never store API keys in code or committed files.

## 🏃 Running the Application

### 1. Start the Backend (Gemini Proxy Server)

The backend service lives in the `server/` directory and handles:
- Secure communication with the Google Gemini API (your API key lives **only** on the server)
- Proxying external meme template images to avoid CORS issues

```bash
cd server
npm install        # first time only

# Set environment variable (varies by OS)
# macOS/Linux:
export GEMINI_API_KEY="your_real_gemini_key"
npm run dev

# Windows (PowerShell):
$env:GEMINI_API_KEY="your_real_gemini_key"
npm run dev

# Or use a .env file as shown above
```

The backend will start on `http://localhost:4000`.

### 2. Start the Angular Frontend

In a new terminal, from the project root:

```bash
npm install        # if not already done
npm run dev
```

The application will be available at `http://localhost:4200`. All `/api` requests are automatically proxied to the backend via `proxy.conf.json`.

### 3. Testing

Run the test suite:

```bash
npm run test
```

Run tests in watch mode (recommended during development):

```bash
npm run test:watch
```

Generate coverage report:

```bash
npm run test:coverage
```

## 🌐 Deployment

### Architecture Overview

This project consists of two deployable services:

1. **Backend (server/)** – Node.js/Express API server
2. **Frontend (Angular)** – Static SPA (Single Page Application)

Both can be deployed independently or together behind a reverse proxy.

### Backend Deployment

Deploy the `server/` directory to any Node.js-compatible platform:

**Recommended Platforms:**
- [Render](https://render.com/) – Free tier available
- [Railway](https://railway.app/) – Pay-as-you-go
- [Cloud Run](https://cloud.google.com/run) – Google Cloud
- [Heroku](https://www.heroku.com/) – Classic Node.js hosting

**Required Environment Variables:**
- `GEMINI_API_KEY` – Your real Gemini API key (never commit to git)
- `ALLOWED_ORIGIN` – Frontend URL (e.g., `https://your-domain.com`)
- `NODE_ENV` – Set to `production`

**Example Render.yaml:**

```yaml
services:
  - type: web
    name: ai-meme-generator-api
    env: node
    buildCommand: cd server && npm install
    startCommand: npm start
    envVars:
      - key: GEMINI_API_KEY
        scope: build,runtime
      - key: ALLOWED_ORIGIN
        value: https://your-frontend.com
```

### Frontend Deployment

Build and deploy `dist/` to a static host:

**Recommended Platforms:**
- [Vercel](https://vercel.com/) – Optimized for Next.js but works with any SPA
- [Netlify](https://www.netlify.com/) – Excellent SPA support
- [GitHub Pages](https://pages.github.com/) – Free, if public repo
- [AWS CloudFront](https://aws.amazon.com/cloudfront/) – CDN distribution

**Build Command:**

```bash
npm run build
```

**Deployment Folder:** `dist/`

**Important:** Configure the frontend's API base URL to point at your deployed backend. This can be done via environment-specific config files or a `.env` file during build.

### Architecture Patterns

**Option 1: Separate Domains**
- Frontend: `https://meme-gen.example.com`
- Backend: `https://api.meme-gen.example.com`
- Frontend's `proxy.conf.json` targets the backend domain

**Option 2: Single Domain with Reverse Proxy**
- Frontend served at `https://meme-gen.example.com/`
- Backend served at `https://meme-gen.example.com/api`
- Use Nginx or your platform's routing to split traffic

## 🐛 Troubleshooting

### Cairo Installation Issues

If you encounter errors installing the `canvas` package:

**macOS:**
```bash
brew install cairo
npm install
```

**Ubuntu/Debian:**
```bash
sudo apt-get install build-essential libcairo2-dev
npm install
```

**Windows:**
Ensure you have Visual Studio Build Tools or Node.js build tools installed:
```bash
npm install --global windows-build-tools
npm install
```

### Backend Won't Start

**Error:** `EADDRINUSE: address already in use :::4000`
- Port 4000 is already in use. Either kill the process or change the port in `server/index.js`.

**Error:** `GEMINI_API_KEY is not set`
- Ensure your `.env` file exists in `server/` or environment variable is exported.

### Frontend Can't Reach Backend

- Verify backend is running on `http://localhost:4000`
- Check browser DevTools → Network tab for `/api/*` requests
- Confirm `proxy.conf.json` is correctly configured
- Clear browser cache (`Ctrl+Shift+Delete` or `Cmd+Shift+Delete`)

### API Rate Limiting

If you hit Gemini API rate limits, the frontend will display an error message. Wait a moment and try again, or consider upgrading your Gemini API plan.

### Session Storage Not Working

If saved memes aren't persisting:
- Check browser storage limits (IndexedDB can fail on low disk space)
- Try clearing browser cache and reload
- Check browser console for storage errors
- Firefox: `about:preferences#privacy` → Clear Storage
